# Практическое занятие № 3. Управление данными в операционных системах

**Цель работы:** Научиться навигации по файловой системе, созданию файлов и изменению прав доступа двумя способами: через графический интерфейс (DE MATE) и через командную строку (CLI).

**Рабочая среда:** Рабочий стол (Desktop).

---

## 📖 Справочник и инструкция

Все задания выполняются в папке **«Рабочий стол»** (`Desktop`).

### 1. Переход на Рабочий стол

* **В графическом интерфейсе (DE MATE):** Откройте файловый менеджер **Caja** (значок «Компьютер» или папка на панели) и перейдите в папку «Рабочий стол».
* **В терминале (CLI):** Используется команда `cd`:
```bash
cd ~/Рабочий\ стол

```


*(Если система на английском языке — `cd ~/Desktop`).*

### 2. Просмотр содержимого папки

* **В DE MATE:** Вы видите значки прямо на столе или в открытом окне папки.
* **В CLI:** Команда `ls`:
* `ls` — просто показать файлы.
* `ls -l` — показать файлы с правами доступа и размером.
* `ls -a` — показать скрытые файлы.



### 3. Создание и редактирование файлов

* **В DE MATE:** Нажать правой кнопкой мыши (ПКМ) $\rightarrow$ *«Создать документ»* $\rightarrow$ *«Пустой файл»*. Открывается двойным кликом в текстовом редакторе **Pluma**.
* **В CLI:** Команда `nano имя_файла.txt`.
* `Ctrl + O`, затем `Enter` — **сохранить**.
* `Ctrl + X` — **выйти**.



### 4. Права доступа (`chmod`)

Права определяют, кто может читать (`r`), изменять (`w`) и запускать (`x`) файл.

| Цифра | Права | Что означает |
| --- | --- | --- |
| **4** | `r--` | Только чтение |
| **6** | `rw-` | Чтение и запись |
| **7** | `rwx` | Полный доступ |

Права задаются из трех цифр (для Владельца / Группы / Всех остальных). Например: `644` или `444`.

## 🛠 Практические задания

### Часть 1. Выполнение через графический интерфейс (DE MATE)

#### Шаг 1. Переход и просмотр

1. Сверните все окна, чтобы видеть ваш **Рабочий стол**.
2. Откройте файловый менеджер **Caja** (двойной клик по иконке «Домашняя папка» на столе).
3. Внутри откройте папку **Рабочий стол**.

#### Шаг 2. Создание файла

1. Нажмите правой кнопкой мыши (ПКМ) на пустом месте Рабочего стола.
2. Выберите **Создать документ** $\rightarrow$ **Пустой файл**.
3. Назовите файл `gui_test.txt`.
4. Откройте его двойным кликом (он откроется в редакторе **Pluma**).
5. Напишите текст: `Файл создан через графический интерфейс MATE.`
6. Нажмите **Файл** $\rightarrow$ **Сохранить** и закройте окно.

#### Шаг 3. Изменение прав доступа

1. Нажмите ПКМ по созданному файлу `gui_test.txt` на Рабочем столе и выберите **Свойства**.
2. Перейдите на вкладку **Права**.
3. В строке **Владелец** смените доступ с «Чтение и запись» на **«Только чтение»**.
4. Закройте окно свойств.
5. Попробуйте снова открыть файл двойным кликом, изменить текст и сохранить. *Система не даст этого сделать, так как файл доступен только для чтения.*

---

### Часть 2. Выполнение через командную строку (CLI)

#### Шаг 1. Навигация и просмотр (`cd` и `ls`)

1. Откройте терминал (сочетание клавиш `Ctrl + Alt + T`).
2. Перейдите на Рабочий стол:
```bash
cd ~/Рабочий\ стол

```


3. Проверьте, что вы видите файл `gui_test.txt`, созданный в первой части:
```bash
ls -l

```



#### Шаг 2. Создание файла (`nano`)

1. Создайте второй файл прямо на Рабочем столе:
```bash
nano cli_test.txt

```


2. Напишите внутри текста: `Файл создан через терминал.`
3. Сохраните файл (`Ctrl + O`, нажмите `Enter`) и выйдите (`Ctrl + X`).
4. Посмотрите на экран Рабочего стола — там мгновенно появится новый значок `cli_test.txt`.

#### Шаг 3. Изменение прав доступа (`chmod`)

1. Проверьте текущие права файла `cli_test.txt`:
```bash
ls -l cli_test.txt

```


2. Сделайте файл доступным **только для чтения** для всех пользователей (код `444`):
```bash
chmod 444 cli_test.txt

```


3. Убедитесь с помощью `ls -l cli_test.txt`, что права изменились на `-r--r--r--`.
4. Верните права на чтение и запись обратно (код `644`):
```bash
chmod 644 cli_test.txt

```
