# Практика 2. Работа в личной папке студента (ФИО)

**Цель:** закрепить базовые команды Linux, работая внутри собственной папки, названной вашим ФИО.

## Команды, которые понадобятся

| Команда | Что делает |
|---------|------------|
| `pwd` | Показывает полный путь к текущей папке |
| `ls` | Выводит список файлов и папок в текущей директории |
| `cd` | Переход в другую папку |
| `mkdir` | Создаёт новую папку |
| `touch` | Создаёт пустой файл |
| `echo` | Выводит текст; с помощью перенаправления можно записать текст в файл |
| `cat` | Показывает содержимое файла на экране |
| `cp` | Копирует файлы или папки |
| `mv` | Перемещает или переименовывает файлы и папки |
| `rm` | Удаляет файлы и папки |

---

## Задания

1. **Создайте папку**, название которой — ваше ФИО (например, «Иванов Иван Иванович»).  
2. **Перейдите** в созданную папку.  
3. **Проверьте**, что вы находитесь именно в ней (узнайте текущий путь).  
4. **Посмотрите**, что находится внутри этой папки.  
5. **Создайте** внутри неё папку `lab2`, а в ней — три подпапки: `src`, `docs`, `backup`.  
6. **Перейдите** в папку `lab2`.  
7. **Проверьте** текущий путь и **выведите** список содержимого.  
8. **Создайте** в папке `src` три пустых файла: `main.c`, `utils.c`, `readme.txt`.  
9. **Посмотрите** список файлов в `src`.  
10. **Запишите** в файл `main.c` строку: `Hello, Linux!`  
11. **Добавьте** в конец файла `main.c` ещё одну строку: `int main() { return 0; }`  
12. **Выведите** содержимое файла `main.c` на экран.  
13. **Запишите** в файл `readme.txt` текст: `Это файл readme для лабораторной работы 2`  
14. **Проверьте** содержимое `readme.txt`.  
15. **Скопируйте** файл `main.c` в папку `backup` под именем `main_backup.c`.  
16. **Скопируйте** файл `readme.txt` в папку `docs`.  
17. **Проверьте** содержимое папок `backup` и `docs`.  
18. **Выведите** содержимое скопированного файла `main_backup.c`.  
19. **Переименуйте** файл `utils.c` в `helpers.c`.  
20. **Запишите** в файл `helpers.c` строку: `// helpers code`  
21. **Переместите** файл `readme.txt` из папки `docs` в папку `backup`, изменив его имя на `readme_backup.txt`.  
22. **Проверьте** содержимое папок `src`, `docs`, `backup`.  
23. **Выведите** содержимое файла `readme_backup.txt`.  
24. **Создайте** временный файл `temp.txt` в папке `lab2`.  
25. **Убедитесь**, что файл появился.  
26. **Удалите** файл `temp.txt`.  
27. **Проверьте**, что файла больше нет.  
28. **Создайте** папку `old` и внутри неё файл `file.txt`.  
29. **Удалите** папку `old` вместе со всем её содержимым.  
30. **Проверьте**, что папки `old` больше нет.  
31. **Вернитесь** на уровень выше (в папку с вашим ФИО).  
32. **Проверьте** текущий путь.  
33. **Снова перейдите** в папку `lab2`.  
34. **Выведите** содержимое всех созданных файлов одной командой: `main.c`, `helpers.c`, `main_backup.c`, `readme_backup.txt`.  
35. **Скопируйте** всю папку `lab2` в новую папку `lab2_copy`.  
36. **Удалите** папку `lab2_copy`.  
37. **Вернитесь** в домашнюю папку.  
38. **Проверьте** текущий путь.

---

**Критерии выполнения:**  
- папка названа вашим ФИО;  
- все перечисленные команды использованы по назначению;  
- файлы созданы, содержат нужный текст;  
- копирование, перемещение и удаление выполнены корректно;  
- вы умеете проверять результат командами `pwd`, `ls`, `cat`.
