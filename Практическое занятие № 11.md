## 3. Краткие теоретические сведения

**Поток** — это последовательность выполнения команд внутри процесса. В одном процессе может одновременно работать несколько потоков.

**Синхронизация потоков** — это согласование выполнения потоков для обеспечения правильной работы с общими данными и ресурсами.

**Гонка данных** — ситуация, при которой несколько потоков обращаются к общим данным, причём хотя бы один поток изменяет их, а доступ не защищён должным образом.

**Критическая секция** — участок программы, в котором происходит работа с общими данными и который необходимо защищать от конфликтующего доступа.

**Блокировка (`Lock`)** — механизм синхронизации, позволяющий ограничить одновременный доступ потоков к защищённому участку кода.

В Python для работы с потоками используется модуль `threading`.

Основные элементы:

- `threading.Thread` — создание потока.
- `threading.Lock()` — создание блокировки.
- `start()` — запуск потока.
- `join()` — ожидание завершения потока.
- `with lock:` — выполнение критической секции под блокировкой с автоматическим освобождением блокировки при выходе из неё.

### Задание 2. Обнаружение гонки данных

**Цель:** исследовать поведение двух потоков, изменяющих одну общую переменную без синхронизации.

1. Создайте файл `task1.py`.
2. Вставьте следующий код:

```python
import threading
import time

counter = 0


def worker():
    global counter

    for _ in range(1000):
        value = counter
        time.sleep(0)
        counter = value + 1


threads = [
    threading.Thread(target=worker),
    threading.Thread(target=worker)
]

for thread in threads:
    thread.start()

for thread in threads:
    thread.join()
```

### Задание 3. Исправление ошибки с помощью блокировки

**Цель:** научиться защищать критическую секцию с помощью `threading.Lock`.

1. Создайте файл `task2.py`.
2. Скопируйте в него следующий код:

```python
import threading
import time

counter = 0
lock = threading.Lock()


def worker():
    global counter

    for _ in range(1000):
        with lock:
            value = counter
            time.sleep(0)
            counter = value + 1


threads = [
    threading.Thread(target=worker),
    threading.Thread(target=worker)
]

for thread in threads:
    thread.start()

for thread in threads:
    thread.join()

print("Ожидаемое значение:", 2000)
print("Фактическое значение:", counter)
```
