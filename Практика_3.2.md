# Практическое занятие № 3. Управление данными в операционных системах (Уровень: Продвинутый)

**Цель работы:** Освоить работу со сложными структурами каталогов, массовым изменением прав доступа, точечным управлением владельцами и специальными атрибутами файлов через графический интерфейс MATE и терминал (CLI).

---

## 📖 Справочник усложненных команд и ключей

В дополнение к базовым командам для сложных задач используются дополнительные параметры:

### 1. Расширенные ключи для `ls` и `chmod`

* `ls -laS` — показать все файлы (включая скрытые) с сортировкой по **размеру** (от больших к меньшим).
* `chmod -R 755 имя_папки` — ключ `-R` (рекурсивно) применяет новые права ко **всем файлам и подпапкам** внутри указанной директории.

### 2. Числовые права доступа (углубленно)

Права записываются тремя цифрами: **Владелец / Группа / Остальные**.
Сумма прав складывается из значений: `4` (чтение $r$), `2` (запись $w$), `1` (выполнение $x$).

* **`750`** — Владелец: $4+2+1=7$ (всё), Группа: $4+0+1=5$ (чтение и запуск), Остальные: $0$ (нет доступа).
* **`700`** — Полный доступ только у владельца. Ни группа, ни остальные зайти в папку не смогут.

## 🛠 Практические задания (Продвинутый уровень)

Все действия по-прежнему выполняются в рабочей папке **«Рабочий стол»** (`Desktop`).

---

### Часть 1. Сложные сценарии в DE MATE (Графический интерфейс)

#### Задание 1.1. Закрытая структура папок

1. Перейдите на **Рабочий стол** через файловый менеджер **Caja**.
2. Создайте папку с именем `Secret_Folder`.
3. Зайдите внутри нее и создайте файл `confidential.txt` с любым текстом.
4. Выйдите обратно на Рабочий стол.
5. Нажмите ПКМ по папке `Secret_Folder` $\rightarrow$ **Свойства** $\rightarrow$ **Права**.
6. В строке **«Группа»** и **«Остальные»** установите права **«Нет»** (Никаких прав).
7. Зайдите во вкладку «Права» и найдите кнопку **«Применить права к вложенным файлам»**.
8. **Проверка:** Попробуйте передать эту папку или открыть ее под другой учетной записью (или попросите соседа по лаборатории открыть её через сеть/свою сессию) — доступ будет полностью закрыт.

#### Задание 1.2. Создание исполняемого скрипта через GUI

1. На Рабочем столе нажмите ПКМ $\rightarrow$ **Создать документ** $\rightarrow$ **Пустой файл**.
2. Назовите файл `system_info.sh`.
3. Откройте его в **Pluma** и вставьте код:
```bash
#!/bin/bash
echo "Текущая дата и время:"
date

```


4. Сохраните и закройте файл.
5. Нажмите ПКМ по `system_info.sh` $\rightarrow$ **Свойства** $\rightarrow$ **Права**.
6. Поставьте галочку **«Разрешить выполнение файла как программы»**.
7. Дважды кликните по файлу `system_info.sh` на Рабочем столе и выберите **«Запустить в терминале»**.

### Часть 2. Сложные сценарии в CLI (Командная строка)

#### Задание 2.1. Рекурсивное управление правами

1. Откройте терминал и перейдите на Рабочий стол:
```bash
cd ~/Рабочий\ стол

```


2. Создайте сложную структуру папок одной командой (используя ключ `-p`):
```bash
mkdir -p Project/src Project/docs Project/bin

```


3. Создайте по одному файлу в каждой подпапке:
```bash
touch Project/src/app.py Project/docs/manual.txt Project/bin/start.sh

```


4. Настройте права для всего проекта одной командой:
* Дайте владельцу полный доступ, а всем остальным — только чтение и вход (`755`) **рекурсивно** для всей папки `Project`:


```bash
chmod -R 755 Project

```


5. Защитите папку с документацией: снимите ВСЕ права для группы и остальных пользователей с папки `Project/docs`:
```bash
chmod 700 Project/docs

```


6. Проверьте результат с помощью команды просмотра прав:
```bash
ls -la Project

```



#### Задание 2.2. Массовая подготовка исполняемых файлов

1. Перейдите в папку `Project/bin`:
```bash
cd Project/bin

```


2. Напишите внутри файла `start.sh` скрипт с помощью `nano`:
```bash
nano start.sh

```


Вставьте строку:
```bash
echo "Проект успешно запущен!"

```


Сохраните (`Ctrl+O`, `Enter`) и выйдите (`Ctrl+X`).
3. Попробуйте запустить файл напрямую:
```bash
./start.sh

```


*(Терминал выдаст ошибку "Permission denied", так как у файла нет прав на выполнение $x$).*
4. Выдайте право на выполнение **только владельцу** (символьным методом или числовым `744`):
```bash
chmod u+x start.sh

```


5. Запустите файл снова:
```bash
./start.sh

```


*(В терминале должна появиться надпись «Проект успешно запущен!»).*

### Задание 3. Аналитическое вызов-задание (Комбинированное)

1. Вернитесь в терминале на Рабочий стол (`cd ~/Рабочий\ стол`).
2. Выполните команду, которая выведет **все** файлы и папки на Рабочем столе, отсортированные по размеру, включая скрытые:
```bash
ls -laS

```


3. Найдите в списке папку `Project` и посмотрите на ее первую букву в столбце прав (там должна стоять буква `d`, означающая *directory*).
4. Заблокируйте доступ к папке `Project` полностью даже для себя (код `000`):
```bash
chmod 000 Project

```


5. Попробуйте зайти в нее через терминал (`cd Project`) или открыть ее мышкой на Рабочем столе в **Caja**.
*Запишите в отчет, что произошло при попытке входа.*
6. Верните папочке исходные права (`chmod 755 Project`), чтобы восстановить рабочий стол.
